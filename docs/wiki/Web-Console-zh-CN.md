# 网页测试台

[Wiki 首页](Home-zh-CN.md) · [English](Web-Console.md)

## 本地启动

在源码仓库执行：

```sh
npm ci
npm run example:web
```

打开 **http://127.0.0.1:3050**，服务默认仅监听本机。PowerShell 中可这样修改端口：

```powershell
$env:WEB_EXAMPLE_PORT = '3051'
npm run example:web
```

npm SDK 包不包含测试台及 Fastify 服务，运行此示例需要源码仓库。

## 操作流程

1. 输入完整 `baseUrl`，或者分别填写协议、IP/主机名和端口。
2. 输入设备账号和密码。
3. 选择 SDK 接口，页面会填入可编辑的 JSON 示例参数。
4. 检查生成的 Node.js 示例代码；接口、参数、地址或用户名变化时，代码同步更新。
5. 发起请求，写入操作每次都需要勾选确认。

账号密码不会持久化。生成代码使用 `process.env.HIKVISION_PASSWORD`，不嵌入密码。较大的 Base64 数据使用占位符，复制后需要自行补入。

测试台覆盖人员、卡片、人脸、批量操作、设备信息与能力集、门控制、历史事件、图片以及时间/NTP 设置。原始请求面板仅允许 GET；实时订阅使用仓库中的 `examples/subscribe.js`。

## 图片与文件路径

人脸支持 URL 模式，也可选择浏览器本地 JPEG 文件转成 Base64。批量人脸支持 URL/Base64，网页接口不读取任意服务器文件。

Buffer 输出通过 Base64 传给浏览器用于预览。文件模式使用生成的文件名保存到 `examples/web/downloads/`，路径属于测试服务所在机器，不是设备或浏览器所在机器的路径。

## 执行限制

网页后端请求体上限为 20 MiB，单次操作最多运行 120 秒。页面断开时取消对应请求，停止尚未开始的批量任务；已送达设备的写入无法撤回。

测试台用于本地开发，不提供远程部署所需的账号管理。运行测试台的机器需要能访问设备，SDK 本身的超时及图片大小限制仍然生效。
